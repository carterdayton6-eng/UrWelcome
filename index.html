UrWelcome Terminal Architecture

Data Sources: UrWelcome connects directly to ESPN's public sports API for live schedules, game lines, and standings across NFL, MLB, NHL, NBA, NCAAF, and UFC.

1. Real-Time Schedules (ESPN API):

All game schedules, team records, matchups, and venue data are fetched live from ESPN's public scoreboard endpoints. Data is cached for 2 minutes to keep the app fast.

2. Betting Lines:

Spread, total, and moneyline data comes from ESPN's odds data when available. If live odds are unavailable for a game, the app displays "Odds unavailable" rather than fabricating numbers.

3. Mathematically Verified 5-Leg Parlays (+335 to +600):

Every game features a 5-leg parlay analyzed from individual safety floors (85–100% hit rates). Combined multipliers are computed to keep total odds strictly between +335 and +600.

4. Exact 10-Game Historical Hit Rates:

Last 3, 5, and 10-game results calculated against the current live market line. Use [-] and [+] buttons to test line adjustments.

🟢 Status: Connected to active NFL, MLB, NHL, NBA, NCAAF, and UFC season feeds via ESPN API.
